# TrackFlow legacy archive

This directory contains historical implementations preserved during the
repository consolidation. Archived projects are excluded from supported
development commands, Docker images, CI, and deployments.

Code is archived only after unique behavior has been migrated to a canonical
project. Do not add features or fixes here. Remove an archived project once its
history is no longer needed in the working tree.

Canonical projects and ports are listed in the repository root `README.md`.
